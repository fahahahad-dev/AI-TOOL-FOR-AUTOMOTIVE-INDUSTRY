=== Binaries ===
Two binaries are provided for each supported operating system: a
production build and a build with debugging features enabled that
contains a '_debug' suffix.  The production build is faster but does
not report internal errors and cannot produce some of the detailed
information we may request when a bug report is submitted.

When submitting issues to technical support, please provide the
complete output that results from using the debug binary.
